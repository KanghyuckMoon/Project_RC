# ZS-040 블루투스 수동 조종

ZS-040은 기판 표기이므로 실제 장착 모듈(HC-05/HC-06 등)과 통신 속도를
확인해야 합니다. 기본값은 **9600 baud, 8N1 데이터 모드**로 가정합니다.
핀·포트·대체 기능·GPIO 클록은 `zs040.h`의 `ZS040_TX_*`, `ZS040_RX_*`
매크로에서 변경합니다. 변경한 핀이 USART1를 지원해야 합니다.
초기 설정 후 일반 데이터 통신으로 사용합니다. 속도는 `zs040.h`의 `ZS040_BAUD_RATE`에서 변경합니다.

| ZS-040 | STM32F411 기본 배선 (미확인) |
| --- | --- |
| TXD | PA10 (D2) / USART1_RX |
| RXD | PA9 (D8) / USART1_TX (3.3V 논리) |
| GND | 공통 GND |
| VCC | 사용 중인 기판의 전원 규격에 맞춰 연결 |

KEY/EN/STATE 핀은 사용하지 않습니다. 실제 연결 상태를 직접 읽지 않으며,
수동 조종 중 명령이 끊긴 시점으로부터 최대 500ms 후 정지합니다.
CubeMX에서 USART1을 비동기 UART로 설정하며, ZS040 드라이버가 최종 통신 설정과 수신 인터럽트를 처리합니다.
수신 오류/버퍼 넘침 시 남은 명령을 폐기하고 수동 정지로 전환합니다.

## 부팅 시 HC-06 자동 설정

`zs040.h`에 이름 `ZS040_DEVICE_NAME = "MoonCar"`, PIN `ZS040_PAIRING_PIN = "0000"`을
정의했습니다. `ZS040_Init()` 후 메인 루프의 `ZS040_Update()`가 다음 순서로 설정합니다.

1. 모듈 기동을 위해 1초 대기 (메인 루프를 차단하지 않음).
2. `AT` → `OK` 확인.
3. `AT+NAMEMoonCar` → `OKsetname` 또는 `OKname` 확인.
4. `AT+PIN0000` → `OKsetPIN` 또는 `OK0000` 확인.
5. 남은 AT 응답을 100ms 동안 폐기한 뒤 조종 수신 활성화.

명령은 개행 없이 전송하며 명령별 송신/응답 제한은 각각 1초입니다.
설정 대기 중 CarApp은 모터를 정지시킵니다. 설정 실패 시 무한 대기하지 않고
기존 모듈 설정으로 조종 수신을 시작합니다. 따라서 실패하면 이름/PIN은 이전 값일 수 있습니다.

디버거의 `zs040_config_status` 값:

| 값 | 의미 |
| --- | --- |
| 0 | 설정 진행 중 |
| 1 | 이름과 PIN 설정 응답 모두 확인 |
| 2 | AT 확인 실패 (연결 중, 통신 속도/배선/펌웨어 확인) |
| 3 | 이름 설정 실패 |
| 4 | PIN 설정 실패 (이름은 적용됐을 수 있음) |
| 5 | 설정 중 UART 오류 또는 응답 버퍼 초과 |

휴대폰과 **블루투스 연결을 끊은 상태로 차량을 켜야** HC-06이 AT 명령을 받습니다.
설정 성공 후 모듈을 껐다 켜고, 휴대폰의 기존 HC-06 페어링을 삭제한 다음
`MoonCar`를 다시 검색하여 `0000`으로 페어링하세요.
펌웨어에 따라 `=`/개행이 필요한 변종은 현재 기본 명령과 다르므로 응답 실패로 표시됩니다.

근거: [HC-06 공급업체 AT 명령 설명서](https://rajguruelectronics.com/Product/708/HC%2006%20TTL%20Bluetooth%20Module.pdf).

## 앱 설정

아직 앱의 실제 프로토콜이 확인되지 않아 아래 **대소문자 구분 ASCII 1바이트**를
기본으로 구현했습니다. 앱의 버튼 전송 문자를 맞추거나 `car_control.c`의
`CarControl_Command()`를 수정하세요. 숫자 문자열/조이스틱 좌표 패킷은 지원하지 않습니다.

| 전송 문자 | 동작 |
| --- | --- |
| `F` | 수동 전진 / 자율 이동 시작 |
| `L` | 수동 후진 |
| `B`, `R` | 수동 좌/우 제자리 회전 |
| `G`, `I` | 수동 전진 좌/우 회전 |
| `H`, `J` | 수동 후진 좌/우 회전 |
| `S` | 현재 모드를 유지하며 정지 |
| `0` ~ `9`, `q` | 수동 PWM 0~90, 100% (초기값 70%) |
| `M` | 수동 모드로 전환하며 정지 |
| `A` | 수동에서 자율 정지 상태로 전환 (사용자 지정 명령) |

수동 방향 버튼은 누르는 동안 **100~200ms 간격 반복 전송**, 놓으면 `S`를 전송하도록
설정하세요. 한 번만 전송하는 앱 설정에서는 0.5초 후 정지합니다.
속도·부가 기능·개행 문자만 받아서는 정지 타이머가 갱신되지 않습니다.
타임아웃 후에는 새 방향 명령이 있어야 다시 움직입니다.

부팅 시 수동 정지 상태입니다. 자율 모드는 `A`로 선택한 뒤 `F`를 한 번 보내면
직진을 시작합니다. 자율 시작 버튼에서 `F`를 한 번만 보내고, 정지 버튼에서
`S`를 따로 보내도록 설정하세요. `S`로 정지한 뒤 `F`로 다시 출발할 수 있습니다.
자율 모드에선 `F` 이외의 방향 명령과 속도 명령을 무시합니다.
자율 이동에는 수동 조종의 500ms 타임아웃이 적용되지 않습니다. UART 수신 오류나
버퍼 넘침은 기존과 같이 수동 정지로 전환합니다.

[HC-05/ZS-040 기판 공급업체 설명](https://protosupplies.com/product/hc-05-zs-040-bluetooth-module/)
은 흔히 사용하는 9600 baud 설정의 참고 자료입니다. 실제 기판 설정은 별도 확인이 필요합니다.
