# 자율주행용 HC-SR04 3개

| 위치 | TRIG 출력 | ECHO 입력 | 인터럽트 |
| --- | --- | --- | --- |
| 전방 | PB0 | PB1 | EXTI1 |
| 좌측 | PC4 | PC5 | EXTI5 (EXTI9_5) |
| 우측 | PC6 | PC7 | EXTI7 (EXTI9_5) |

세 센서는 차체 전면에 장착합니다. 가운데 센서는 정면, 좌우 센서는 정면에서 각각 바깥쪽으로 약 30°를 향합니다.

각 센서의 VCC는 5V에 연결하고 STM32 및 모터 드라이버와 GND를 공통으로 연결합니다.
ECHO는 5V 신호이므로 센서마다 전압 분배기를 적용합니다. ECHO에서 2.2kΩ을 거쳐
STM32 ECHO 입력에 연결하고, 같은 입력에서 3.3kΩ으로 GND에 연결하면 약 3.0V가 됩니다.
TRIG는 STM32 3.3V 출력입니다. 모듈이 3.3V를 인식하지 못하면 논리 레벨 변환기를 사용합니다.

- `Project_Race.ioc`에서 TRIG는 초기 LOW의 푸시풀 출력, ECHO는 풀다운 및 양쪽 에지 EXTI로 설정합니다.
- TIM5는 1MHz의 32비트 자유 실행 카운터로 쓰며 각 센서는 전방 → 좌측 → 우측 순서로 약 210ms마다 갱신됩니다. 센서 간 트리거 간격은 70ms입니다.
- 트리거 폭은 12µs, 응답 제한은 45ms이며, 거리(cm)는 ECHO 폭(µs)을 58로 나눈 값입니다.
- `HCSR04_Read(HCSR04_FRONT, &distance_cm)`처럼 방향별로 읽을 수 있으며, 2~400cm 범위 밖의 값, 응답 없음, ECHO 고정 HIGH, 300ms가 지난 값은 무효입니다.
- `HCSR04_GetReading()`은 거리, 측정 시각, 센서 상태를 반환합니다. 제한 시간 안에 끝난 400cm 초과 펄스는 범위 초과로, 상승 에지 없이 끝난 측정은 무응답으로 표시합니다. 상승 에지 후 제한 시간 안에 떨어지지 않거나 트리거 전에 ECHO가 HIGH인 경우에는 ECHO HIGH로 표시합니다.
- MoonCar에서 연결이 의심되는 센서를 확인하려면 차량을 정지시키고 해당 센서 정면 약 20~30cm에 평평한 물체를 놓습니다. 거리 표시가 계속 나오지 않으면 표의 핀과 센서 전원, 공통 GND, ECHO 전압 분배기를 확인합니다. 무응답만으로는 반사파 부재와 배선 문제를 구별할 수 없습니다.
