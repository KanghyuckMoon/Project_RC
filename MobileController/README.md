# MoonCar Android 컨트롤러

가로 화면에서 Bluetooth Classic SPP로 RC카를 조종합니다. Android 6.0 이상에서 실행되며, 이 저장소의 STM32 펌웨어와 ZS-040의 HC-06 계열 모듈을 기준으로 만들었습니다. Arduino를 차량 제어기로 사용할 경우 동일한 ASCII 명령을 처리하는 스케치가 필요합니다.

## 설치 및 조작

1. Android 휴대폰에 디버그 APK를 설치합니다. 차량을 켠 뒤 Android 블루투스 설정에서 `MoonCar` 또는 `HC-06`을 페어링합니다. 현재 펌웨어에서 모듈 이름 설정이 적용됐다면 PIN은 `0000`입니다.
2. 앱의 **블루투스 연결**에서 페어링한 차량을 고릅니다. Android 12 이상에서는 근처 기기 권한을 허용합니다.
3. **수동** 모드에서 출력값을 고르고 가속 페달을 누릅니다. 페달을 누른 채 핸들을 좌우로 돌리면 방향이 바뀝니다. 핸들을 놓으면 직진 방향으로 돌아오고, 페달을 놓으면 정지합니다.
4. **자율주행**을 선택한 뒤 **이동 시작**이나 **정지**를 누릅니다. **수동**으로 돌아갈 때는 정지 명령을 먼저 보냅니다.

앱은 주행 명령을 보낸 상태를 표시합니다. 현재 펌웨어의 자율 이동은 PWM 40의 직진이며, 차량에서 앱으로 수신 확인이나 센서 정보가 돌아오지 않습니다. 앱에서 연결을 해제하거나 앱을 벗어나면 연결이 살아 있는 동안 정지 명령을 보냅니다. 주행 중 블루투스 신호가 갑자기 끊기면 수동은 펌웨어 타임아웃으로 정지하지만, 기존 자율 모드는 정지 명령이 도착할 때까지 계속 이동할 수 있습니다.

## 명령

| 조작 | 전송하는 ASCII 바이트 |
| --- | --- |
| 연결, 수동 선택 | `SM` |
| 자율주행 선택 | `SA` |
| 수동 페달 유지 | 출력 `0`–`9` 또는 `q`, 이어서 `F`(직진), `G`(좌), `I`(우)를 120ms 간격으로 전송 |
| 자율 이동 시작 | `F` 1회 |
| 정지 | `S` |

출력은 펌웨어 PWM 비율입니다. 좌우 조향은 손을 뗄 때 복귀하는 핸들을 사용하며, 펌웨어에 맞춰 가운데·좌회전·우회전으로 구분됩니다. 명령에는 개행을 붙이지 않습니다.

## 소스에서 빌드

Android Studio에서 이 폴더를 열고 Android SDK 36과 JDK 17 이상을 선택한 뒤 디버그 APK를 빌드합니다. Gradle 9.1.0이 설치된 환경에서는 `gradle :app:assembleDebug`로 빌드할 수 있습니다. 결과는 `app/build/outputs/apk/debug/app-debug.apk`에 생성됩니다.
