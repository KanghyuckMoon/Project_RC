# MoonCar Android 컨트롤러

가로 화면에서 Bluetooth Classic SPP로 RC카를 조종합니다. Android 6.0 이상에서 실행되며, 이 저장소의 STM32 펌웨어와 ZS-040의 HC-06 계열 모듈을 기준으로 만들었습니다. Arduino를 차량 제어기로 사용할 경우 동일한 ASCII 명령을 처리하는 스케치가 필요합니다.

## 설치 및 조작

1. Android 휴대폰에 디버그 APK를 설치하고 차량을 켭니다. 앱에서 **블루투스 연결**을 누르고 검색 권한을 허용합니다. Android 12 이상은 근처 기기 권한을, Android 11 이하는 검색에 필요한 위치 권한을 사용합니다.
2. 페어링 목록과 주변 Classic·BLE 검색 결과에서 `MoonCar` 또는 `HC-06`을 고릅니다. 처음 연결하는 기기는 Android 페어링을 완료하면 연결이 시작됩니다. 현재 펌웨어에서 모듈 이름 설정이 적용됐다면 PIN은 `0000`입니다. BLE 전용 기기도 목록에 표시되며, 차량에 연결하려면 Bluetooth Classic SPP 모듈이 필요합니다.
3. **수동** 모드에서 출력값을 고르고 **가속** 또는 **후진** 페달을 누릅니다. 페달을 누른 채 핸들을 좌우로 돌리면 조향할 수 있습니다. 핸들을 놓으면 직선 방향으로 돌아오고, 페달을 놓으면 정지합니다.
4. **자율주행**을 선택하면 새 센서 측정값을 받은 뒤 자동으로 주행을 시작합니다. 멈추려면 **정지**, 다시 움직이려면 **주행 재개**를 누릅니다. **수동**으로 돌아갈 때는 정지 명령을 먼저 보냅니다.

화면 하단의 전방·좌측·우측 카드에 초음파 거리 또는 센서 응답 상태가 표시됩니다. 자율주행에서는 차량이 모터 A/B에 지시한 PWM도 표시합니다. 업데이트 후 1.8초 동안 센서 정보가 수신되지 않으면 기존 표시를 지웁니다.

## 앱에서 FPV 영상 보기

1. [ESP32-CAM 스케치](../ESP32Cam/README.md)를 업로드한 카메라에 5V 전원을 연결합니다. Android의 Wi-Fi 설정에서 `RC-CAM`에 연결합니다. 기본 비밀번호는 `RCcar2026!`입니다. 인터넷 없음 안내가 뜨면 연결을 유지합니다.
2. MoonCar 앱에서 **FPV 켜기**를 누릅니다. 중앙에 전방 영상이 뜨면 **블루투스 연결**에서 차량에 연결합니다. 기존 수동 페달·핸들, **자율주행**, **정지**와 초음파 표시를 영상과 함께 사용할 수 있습니다.
3. FPV 사용 중 영상 연결이 끊기거나 새 프레임이 1.5초 동안 들어오지 않으면 앱이 블루투스로 정지 명령을 보내고 영상을 다시 연결합니다. 영상이 돌아오면 수동 페달을 다시 누르거나 **주행 재개**를 눌러 출발합니다. 카메라 없이 주행하려면 **FPV 끄기**를 누른 뒤 조작합니다.

앱은 `http://192.168.4.1:81/stream`으로 연결합니다. 카메라 스트림은 한 번에 한 곳에서 열 수 있으므로 MoonCar에서 FPV를 켜기 전에 브라우저 영상 탭을 닫습니다. 자율주행은 차량의 초음파 센서로 판단합니다.

## 주행 상태와 연결

특정 센서에 계속 **응답 없음**이 뜨면, 정지 상태에서 해당 센서 정면 약 20~30cm에 평평한 물체를 놓아 거리 표시가 바뀌는지 확인합니다. 빈 공간에서도 반사파에 따라 무응답이 나올 수 있습니다.

앱에서 연결을 해제하거나 앱을 벗어나면 연결이 살아 있는 동안 정지 명령을 보냅니다. 주행 중 블루투스 신호가 갑자기 끊기면 수동은 펌웨어 타임아웃으로 정지하지만, 자율 모드는 정지 명령이 도착할 때까지 주행을 계속할 수 있습니다.

## MoonCarGame

MoonCarGame은 기본 MoonCar와 함께 설치할 수 있는 별도 Android 앱입니다. 실제 차량을 수동으로 조종하며 가상 라이벌 코멧·벡터·솔라와 3랩을 달립니다. 화면은 현재 랩, 기록, 실시간 순위와 다음 체크포인트를 표시합니다. 아이템은 없습니다.

1. [체크포인트 카드 4장](race-gates.html)을 A4 가로, 컬러, 100% 배율로 인쇄합니다. 코스 옆에 1 → 2 → 3 → 4 순서로 세우고, 각 카드의 색상 블록이 다가오는 카메라를 향하게 놓습니다. 정면에서 잠시 가까이 볼 수 있도록 코스를 배치합니다.
2. ESP32-CAM을 켠 뒤 휴대폰을 `RC-CAM` Wi-Fi에 연결합니다. MoonCarGame을 열고 영상이 표시되면 **블루투스 연결**을 누릅니다. 출발 지점은 결승선 4를 통과한 직후, 1번으로 향하는 위치입니다.
3. **레이스 시작**을 누르고 3초 카운트다운이 끝나면 주행합니다. 화면에서 다음 번호가 바뀌면 체크포인트가 기록된 것입니다. 카드를 놓쳤다면 그 카드가 카메라에 정면으로 크게 보이도록 다시 접근합니다. 1–4를 순서대로 기록하면 1랩입니다.
4. 3랩째 결승선을 통과하면 최종 순위와 기록이 표시됩니다. 경기 중 **정지**는 차량을 멈추고, **레이스 종료**는 경기를 중단합니다. 영상 또는 블루투스 연결이 끊기면 해당 경기가 중단됩니다.

라이벌은 가상 카트이며 랩당 약 24~30초의 페이스로 달립니다. 플레이어 순위는 통과한 체크포인트와 다음 카드에 접근한 정도로 계산합니다. FPV에 표시되는 라이벌 위치는 체크포인트 영상과 레이스 진행도에 따른 추정입니다.

## 명령

| 조작 | 전송하는 ASCII 바이트 |
| --- | --- |
| 연결, 수동 선택 | `SM` |
| 자율주행 선택 및 출발 | `SAF` |
| 가속 페달 유지 | 출력 `0`–`9` 또는 `q`, 이어서 `F`(전진), `I`(좌), `G`(우)를 120ms 간격으로 전송 |
| 후진 페달 유지 | 출력 `0`–`9` 또는 `q`, 이어서 `L`(후진), `J`(좌), `H`(우)를 120ms 간격으로 전송 |
| 자율 주행 재개 | `F` 1회 |
| 정지 | `S` |
| 센서 정보 요청 | `?` (연결 중 약 360ms 간격) |

출력은 펌웨어 PWM 비율입니다. 좌우 조향은 손을 뗄 때 복귀하는 핸들을 사용하며, 펌웨어에 맞춰 가운데·좌회전·우회전으로 구분됩니다. 명령에는 개행을 붙이지 않습니다.

차량은 `@US,D,62,N,0,F,400,71,71` 같은 한 줄을 개행으로 끝내 응답합니다. 전방·좌측·우측의 상태와 cm 값 다음에 모터 A/B 명령값을 보냅니다. 상태 코드는 `D` 거리 측정, `F` 범위 초과, `N` 무응답, `H` ECHO HIGH, `P` 짧은 펄스, `S` 오래된 측정, `W` 첫 측정 대기입니다.

## 소스에서 빌드

Android Studio에서 이 폴더를 열고 Android SDK 36과 JDK 17 이상을 선택합니다. Gradle 9.1.0이 설치된 환경에서는 다음 명령으로 두 앱을 빌드합니다.

| 앱 | 빌드 명령 | APK |
| --- | --- | --- |
| MoonCar | `gradle :app:assembleControllerDebug` | `app/build/outputs/apk/controller/debug/app-controller-debug.apk` |
| MoonCarGame | `gradle :app:assembleGameDebug` | `app/build/outputs/apk/game/debug/app-game-debug.apk` |
